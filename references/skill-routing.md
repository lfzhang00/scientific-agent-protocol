> 技能检测、阶段路由与缺失处理的完整说明。

BioInfo、BioLab、BioStats 是常设、平级专家；skill 是完成其本轮任务的方法资源，二者不要混同。BioStats 默认审查生信与湿实验的统计依据，不以找到某个 skill 为参与前提；BioTarget 是 BioInfo 按需加载或由主协调者单独委派的策划专项，不是必装 skill 或第四个默认专家。

#### 检测和选择

1. 优先查看当前会话提供的技能目录及其名称、描述和位置；若宿主提供技能列举接口，按需使用。没有目录时，只检查用户指定或宿主明确支持的技能位置，不扫描整个硬盘，也不把未知目录当作已安装技能。
2. 先判断当前阶段和交付物，再按技能描述匹配。下表是优先候选，不是要求所有用户都安装这些技能；名称相同也不保证内容相同，内容适配性需通过阅读确认。
3. 用户明确指定的技能优先。选定后先读取完整 `SKILL.md`，仅在需要时读取其附属资料，核实必要工具、数据和运行依赖。沿用同一会话中已读且未变化的版本，阶段或环境变化时重评。
4. 不同交付物可使用不同技能；制图、文档渲染等辅助技能仅负责对应产物。第二个重叠学术技能只能在冻结第一版成果后独立审查，之后由主协调者整合。
5. 开始时用一句话说明“阶段—负责角色—所选技能”；后续只报告切换或重要缺口。子智能体应确认自己能访问并读取所选技能，再按其要求执行，不能仅返回“已使用某技能”。
6. 依据真实执行情况区分：已检测但未选用、已读取并采用、因依赖缺失仅采用部分流程、不可用。读取文件不代表其中脚本、检索、验证步骤全部完成。

#### 默认阶段路由

| 工作阶段或交付物 | 优先候选 skill | 使用边界 |
| --- | --- | --- |
| 文献检索、检索策略与参考文献文件 | nature-academic-search | 用于发现来源，不把题录当作全文证据 |
| 指定期刊家族的主张与文献匹配 | nature-citation | 只在其范围适合任务时使用 |
| 单篇论文精读／全文双语阅读材料 | nature-paper-card／nature-reader | 按目标二选一，不重复精读 |
| 作者、年份、卷期页及 DOI 核验 | nature-ref-verifier | 与科学内容评价区分 |
| 统计方法与报告审查 | nature-statistics | 由 BioStats 独立审查生信与湿实验的统计报告；不将其当作全部设计、计算或生信执行框架 |
| 一般实验或人群研究设计、研究问题澄清、端到端研究流程 | academic-research-suite | 读取后选择相关工作流；窄领域技能已覆盖时优先窄技能；用户明确指定时遵从 |
| 研究计划、开题报告或项目书 | researchwrite | 描述证据路线、资源与可行性，不编造预实验 |
| 论文结构与初稿／已有文字润色 | nature-writing／nature-polishing | 按起草或润色阶段选择 |
| 科研图表／论文汇报幻灯片 | nature-figure／nature-paper2ppt | 按产物选择并验证结果 |
| 独立审稿／审稿意见回复 | nature-reviewer／nature-response | 先固定被评价版本，再审查或回应 |
| 数据与代码可用性、存储与 FAIR 信息 | nature-data | 实际核实获取条件 |
| 流程偏差、错误恢复与迭代复盘 | self-evolution | 由主协调者负责流程反馈，不代替学术判断 |

对于直接的数据处理或模型实现，若没有覆盖该任务的技能，就按可复现分析规范直接执行；不为凑技能名称而套用不适合的工作流。ARS 与 nature-writing、nature-polishing 不在同一起草阶段重复使用；ARS reviewer 与 nature-reviewer 不在同一审查阶段重复使用。

BioStats 的样本量规划、模型选择及计算按任务授权、真实数据结构和可追溯方法开展；没有适用 skill 不等于免除审查，也不能把读取 `nature-statistics` 当作已经完成计算。BioTarget 使用专项中的阶段路由，BioLab 与 BioStats 仍分别承担实验可行性与统计把关，不重复起草同一成果。

#### 缺失与兼容处理

- 名称未找到：在可用目录中寻找功能相符的技能，阅读后说明替换理由；不可把相似名称当作等价能力。
- 用户指定的技能不可用：明确报告。若该技能是任务必要条件，暂停依赖它的部分并说明缺口；若只是优选方式，可说明限制后采用等价技能或本文内置流程。
- 可读但依赖缺失：只使用可执行部分，列出未完成的关键步骤；若缺口影响结论，不通过措辞掩盖或强行给出确定结论。
- 没有任何技能系统：本文仍可作为普通提示词执行，使用直接的方法、来源核验和反馈检查；明确标注未使用外部 skill。
- 不将本文件当成安装器，不自动下载技能、运行未经审查的脚本或安装依赖。用户要求安装时，再按目标环境的正式安装流程处理。
- 提示词不能保证宿主提供技能发现、工具访问或子智能体能力。只能对当前会话可见、可访问的范围进行检测。
