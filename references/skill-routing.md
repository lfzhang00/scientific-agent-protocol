## 检测和选择

专家是分工角色，skill 是执行任务的方法资源；BioStats 的默认参与不取决于某个 skill 是否安装。

1. 先看当前会话的技能目录、名称、描述和位置，必要时使用宿主列举接口。没有目录时只检查用户指定或宿主支持的位置，不扫描整个硬盘，不预设安装路径。
2. 按阶段和交付物选最少技能，用户明确指定的优先。读取完整 `SKILL.md`，按需读取附属资料，核实工具、数据和依赖；已读且未变的版本可复用。
3. 每阶段、每成果只用一个主要学术技能。第二个重叠技能仅独立审查冻结版本，再由协调者整合；制图和文档渲染等辅助技能负责对应产物。
4. 用一句话说明“阶段、负责角色、所选技能”，后续只报告切换和重要缺口。子智能体须确认能读取；状态区分为发现但未用、读取采用、部分执行、不可用。读取文件不能作为脚本、检索或验证已完成的依据。

## 阶段路由

| 工作 | 优先候选 skill | 范围 |
| --- | --- | --- |
| 文献检索、策略与参考文献文件 | nature-academic-search | 发现来源，题录不能代替全文 |
| 指定期刊家族的主张与引文匹配 | nature-citation | 仅在任务期刊范围适用时 |
| 单篇精读／全文双语材料 | nature-paper-card／nature-reader | 按目标二选一 |
| 作者、年份、卷期页和 DOI 核验 | nature-ref-verifier | 与科学内容评价分开 |
| 统计方法和报告审查 | nature-statistics | BioStats 审查两侧报告；设计和实际计算另按数据与授权开展 |
| 一般实验或人群研究设计、问题澄清、端到端流程 | academic-research-suite | 选择适用工作流，窄领域任务优先窄技能 |
| 研究计划、开题或项目书 | researchwrite | 基于证据、资源与可行性 |
| 论文起草／已有文字润色 | nature-writing／nature-polishing | 按阶段选择 |
| 科研图表／论文汇报 | nature-figure／nature-paper2ppt | 按产物选择并验证 |
| 独立审稿／审稿回复 | nature-reviewer／nature-response | 先固定被评版本 |
| 数据代码可用性、存储与 FAIR | nature-data | 核实实际获取条件 |
| 流程偏差、恢复与复盘 | self-evolution | 协调者负责，遵守核心协议的反馈边界 |

没有适合的数据处理或模型技能时，直接按可复现规范执行。ARS 与 nature-writing、nature-polishing 不在同一起草阶段重复使用；ARS reviewer 与 nature-reviewer 不在同一审查阶段重复使用。BioTarget 按所需阶段选技能，BioLab 和 BioStats 仍各自审查，不重复起草同一成果。

## 缺失处理

- 名称未找到：阅读功能相符的候选技能再决定替换，说明理由；相似名称不证明能力等价。
- 指定技能不可用：报告缺口。若属必要条件，暂停依赖它的部分；若只是优选方式，采用适用替代或内置流程。
- 依赖不全：仅执行可用部分，列明未完成步骤及其对结论的影响。没有技能系统时使用直接方法和反馈检查，并说明未使用外部 skill。
- 检测只读，不自动下载、安装或修改第三方内容。用户要求安装后，按目标环境流程处理。技能缺失不免除统计审查，也不允许声称完成了未执行的计算。
